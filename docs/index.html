Data quality audit

Daily usage logs for 40 people over 120 days, simulated with a fixed seed because real per-app logs with day labels are private. Realistic recording problems were injected so the cleaning stage has genuine work to do.

Six approaches, one test month

Why this model

    Limitations

    The data is simulated, so results must be confirmed on real, consented usage logs. A person needs 7 days of history before a baseline exists. Labels are self-reported and about 7% are noisy, which is why almost every remaining error is between neighbouring classes. The project identifies usage-pattern changes only and does not diagnose addiction or any medical or psychological condition.
